# MotionFreela Strategic Pricing Capstone 🎥

Developing a strategic pricing recommendation for a subscription-based video production company to scale sustainably.

### 📊 Dashboard Purpose & Logic
The interactive dashboard serves as a strategic decision-support tool:
* **Simulate Impact:** Visualize how subscription price changes affect revenue and production load.
* **Filter by Service:** Interactive controls for video types (explainer, social ads) and durations.
* **Identify Patterns:** Benchmarks turnaround times against content complexity.

### 🛠️ Methodology
1. **Data Collection:** Integrated internal pricing models with external Kaggle market research.
2. **Pricing Patterns:** Identified competitor tiers and content delivery timelines.
3. **Visualization:** Built intuitive Power BI visuals for non-technical stakeholders.
